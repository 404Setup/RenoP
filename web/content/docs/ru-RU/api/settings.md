# API настроек

Маршруты требуют администратора или API Token с `admin:settings` либо `admin:repositories` в зависимости от операции.
Ответы используют protobuf, если это задано в `proto/api/v1/api.proto`.

## Получение доменов настроек

- **Путь**: `GET /api/settings/domains`
- **Ответ**: стабильные имена, поддерживаемые сервером, включая `server`, `proxy`, `storage`, `updater` и `frontend`.

## Страницы настроек в браузере

Для каждого из 13 объявленных разделов предусмотрена отдельная страница. На большом экране список разделов
находится рядом с формой, на маленьком используется селектор. Кнопки назад и далее следуют тому же порядку.
Открытие страницы загружает только её конфигурацию, а не все настройки сервиса.

Черновик каждой страницы сохраняется при смене раздела или языка. Сохранение обновляет только активную страницу
и временно блокирует редактирование и переключение. Ошибка сохраняет черновик; отмена изменений после подтверждения
заново загружает страницу. Несохранённые изменения отмечаются в навигации. Перезагрузка или закрытие браузера
вызывает предупреждение, но черновики хранятся лишь в памяти и удаляются при выходе или смене аккаунта. Уже сохранённые
секреты остаются скрытыми; введённые секреты удаляются из черновика после успешного сохранения.

GPG остаётся частью конфигурации сервиса. Лимиты глобальных команд, квоты, регистрация, кэш, почта, OAuth и безопасность доменов имеют отдельные страницы. Юридические документы и единые настройки OAuth используют бинарный protobuf, остальные сохраняют документированные форматы. Подписи и подсказки связаны с полями, а навигация переносит фокус на заголовок.

Активный раздел, отметки черновиков и вторичный текст используют общие цвета светлой и тёмной темы.

## Чтение и изменение домена

- **Чтение**: `GET /api/settings/domain/:name`
- **Изменение**: `PUT /api/settings/domain/:name`
- **Поведение**: схема зависит от `:name`. Неизвестные поля и неверные значения отклоняются. Изменения хоста, порта,
  TLS, базы данных и некоторых параметров выполнения могут потребовать перезапуск.

**Внешний вход**: `GET /api/settings/oauth-providers` возвращает бинарный protobuf `OAuthSettings` со встроенным GitHub, клиентами без секретов и шаблонами. `PUT /api/settings/oauth-providers` требует `replace_providers: true` и список `providers`, атомарно сохраняя обе группы в пределах 128 KiB. Поддерживаются GitHub и до 12 других клиентов. Отсутствие GitHub сохраняет его; отключите запись и примените `clear_client_secret` для удаления данных. Пустой список удаляет только другие клиенты. `revocation_secret` доступен лишь для записи: пустое значение сохраняет его для того же клиента, `clear_revocation_secret` удаляет. Совместимые endpoints `GET /api/settings/github-oauth` и `PUT /api/settings/github-oauth` сохраняют JSON и управляют теми же настройками GitHub.

## Настройки репозиториев

Предпочтительны маршруты `/api/settings/repositories`. Maven-алиасы сохранены для совместимости.

Изменения фиксируются в базе до замены активной конфигурации. Удаление последнего репозитория сохраняется
после перезапуска; старый YAML используется только для первоначальной миграции.

### Список репозиториев

- **Путь**: `GET /api/settings/repositories`
- **Алиас**: `GET /api/settings/maven/repositories`

### Создание, изменение, удаление и миграция

- **Создать или изменить**: `PUT /api/settings/repositories/:name`
- **Удалить**: `DELETE /api/settings/repositories/:name`
- **Миграция Maven/files**: `POST /api/settings/repositories/:name/migrate/:target`, где `:target` — `maven` или
  `files`. Объекты не перемещаются; при возврате в Maven каталог перестраивается.

## Перестроение поискового индекса

- **Путь**: `POST /api/settings/index/rebuild`
- **Поведение**: отправляет объединяемую фоновую задачу и не запускает две перестройки параллельно.

## Срок резервирования доменов публикации

`GET /api/settings/maven-domains` и `PUT /api/settings/maven-domains` используют JSON.
Список настроек содержит `maven_domains`. Значение по умолчанию:

```json
{"release_value":2,"release_unit":"year"}
```

`release_value` — целое число от 1 до 100; `release_unit` принимает `month` или `year`, расчёт выполняется по календарю
UTC.
База настроек хранит эти поля в `maven_domains`. Сохранённое изменение применяется к новым защитным блокировкам,
не меняя существующие даты освобождения или отдельный 31-дневный срок добровольного закрытия.
См. [состояние доменов Maven](maven.md).

[Правовые документы и cookie](../configuration/legal.md)

Страницы настроек, редакторы провайдеров и зависимые поля используют отменяемые переходы с учётом уменьшения анимации. Пустые списки оформлены общим уведомлением. Закрытые списки выбора не удерживают меню и обработчики документа: они создаются при открытии.

Встроенные ресурсы передаются потоком из исполняемого файла. RenoP хранит тип, размер и ETag без дополнительной копии каждого пакета и сжатого варианта в куче Go. Согласование сжатия и условные запросы сохраняются.

[Проверка безопасности](../security/captcha.md)

`capacity_limit_bytes` задаёт лимит сохранённых байтов репозитория; `0` означает отсутствие лимита. Интерфейс использует MiB. Для Disk и S3 учитываются артефакты, контрольные суммы, объекты на проверке и кэш зеркал, без временных копий. Резервирование перед фиксацией объединяет параллельные загрузки под одним лимитом. Превышение возвращает `507` и `repository_capacity_exceeded`; корректный ответ зеркала можно передать без кэширования. Снижение лимита ниже текущего объёма не мешает чтению. После внешнего изменения хранилища перестройте индекс или перезапустите сервер для пересчёта. Пропуск необязательного поля старым клиентом сохраняет прежний лимит.

Правовые документы находятся в Frontend и сохраняются атомарно вместе с оформлением; пропуск `legal` сохраняет документы. Управление индексом перенесено в Storage, старые endpoints доступны. Server показывает IP/порт, TLS, базу и параметры производительности; изменения listener и базы требуют перезапуска.
